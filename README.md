# ProtoMon-Yahtzee

ProtoMon is a reactive onchain roguelite dice battler: instant optimistic gameplay, verifiable L2 settlement, ERC-4337 session-key UX, and automatic cross-chain badge rewards via Reactive Network.

## Web App

The Next.js app lives in `web/` and was initialized from the command line with `npx create-next-app@latest`.

Development commands:

- `cd web`
- `pnpm dev`
- `pnpm lint`
