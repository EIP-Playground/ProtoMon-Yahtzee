# 🚀 游戏设计文档：《协宝大乱斗：元素共鸣》

**(ProtoMon: Elemental Alchemy)**

**一句话定位 (Slogan):** 首款基于 Reactive Network 驱动的“无信任跨链肉鸽”游戏。将枯燥的 EIP 协议化为魔法大招，在 16-bit 宝可梦风的“卡尔式搓招”中，重塑全链游戏的策略极限。

## 1. 核心概述 (Overview)

- **游戏类型：** 跨链全链游戏 (FOCG) / Roguelite 策略 / 骰子构筑 (Dice-builder)
- **美术风格：** 像素风（类似《宝可梦：绿宝石》），融合“东方玄幻神道教”与“赛博朋克 Web3 梗”。
- **核心目标：** 在 13 回合的极限生存战中，利用元素骰子和 EIP 派生技能击杀 Boss，获取局外代币，最终触发 L1 主网的高价值资产跃迁。

------

## 2. 跨链架构 (The Web3 Architecture)

游戏首创 **“体验在云、资产在链、触发在网”** 的双轨异步架构：

1. **链下极速盲盒 (Next.js 乐观定序器)：** 充当极速 RNG（随机数生成器），提供带签名的防篡改骰子结果，实现 0 延迟的掷骰体验。
2. **高频绞肉机 (L2 智能合约)：** 局内扣血、结算、符文逻辑 100% 部署在 Base/Sepolia 等廉价 L2，支持 OpenClaw 等 AI Agent 无缝读取合约原生接入。
3. **跨链大动脉 (Reactive Network - 核心技术)：** 监听 L2 的 `BossDefeated`（通关）事件，作为无信任中继，自动触发跨链操作。
4. **荣耀宝库 (L1 主网结算)：** 接收 Reactive 触发，自动为玩家 Mint 灵魂绑定徽章 (SBT) 或进化高价值 NFT，消灭中心化发奖服务器。

------

## 3. 战斗系统：13回合的生死炼金局 (Combat System)

战斗基于魔改版的《快艇骰子》，抛弃数字，采用**金、木、水、火、土、气**六大元素骰子（默认 5 颗，可通过局内道具增加）。

玩家的“计分板（魔导书）”分为两大核心策略区：

### A. 上半区：元素共鸣映射板（稳定输出 & 充能）

- **机制：** 6 个槽位对应 6 种元素。当牌型不佳时，在此处结算纯粹的元素伤害（平 A）。
- **六行生克映射：** 分值倍率 (1x - 6x) 取决于出战的 ProtoMon 的“六行本命”。相生元素伤害极高，相克元素伤害极低。
- **觉醒能量槽 (Limit Break)：** 每次填入上半区，积累“觉醒能量”。满 63 点将触发【元神觉醒】，瞬间回血并劈下天道神雷。

### B. 下半区：EIP 招式表（战术爆发 & 构筑）

- **机制：** 7 个牌型槽位（三条、四条、葫芦、小顺、大顺、快艇、全选）。
- **技能装配：** 玩家开局将 EIP 派生技能装填进槽位。**同一技能放在不同槽位，会产生变异效果**（例如：冰霜技能在“三条”是单体减速，在“快艇”是群体绝对零度冻结）。
- **释放条件：** 必须掷出对应牌型才可点击【⭐ 释放 (CAST)】。

### ☠️ 终极限制：13回合狂暴秒杀

计分板的 13 个槽位对应 13 次出手机会。当 13 个格子全满时，若 Boss 依然存活，将无视一切防御触发“狂暴终结技”秒杀玩家。强制校验玩家的极限 DPS 构筑能力。

------

## 4. 局内成长：东方玄幻商店 (Roguelite Shop)

击败怪物获得的局内金币，可在此购买极具东方神道教色彩的道具：

1. **【山海奇物】 (Relics / 被动符文)：** 包装为“千机鲁班匣”。提供全局被动增益（如：增加骰子数量、某种元素变百搭、回合回血等）。最多携带 5 个。
2. **【周天星象】 ( / 倍率卡)：** 包装为“寻星罗盘”。点亮星宿，永久提升某一种牌型槽位（如葫芦）的伤害倍率。
3. **【秘术符箓】 (Talismans / 消耗品)：** 包装为“锦囊御守”。一次性战术道具，可强行改写某颗骰子的元素或提供单回合无敌。
4. **【造化金丹】 (Elixirs / 永久属性)：** 包装为“紫金宝葫芦”。吃下后永久提升协宝的血量上限或初始能量。

## 5. 初始御三家 (The ProtoMons)

玩家开局需选择一只协宝，决定了五行天赋、伤害乘数与专属核心特质：

1. **🔥 焱炽狐 (Ignis Fox) - 爆发/经济流**
   - *五行映射：* 火(6x 最高) ➡️ 木 ➡️ 气 ➡️ 土 ➡️ 金 ➡️ 水(1x 最低)
   - *专属特质【流动性挖矿】：* 摇出金元素可生成生息代币，下回合结算时烧毁转化为金币或伤害增幅。
2. **💧 玄水龟 (Aqua Tortoise) - 运营/防御流**
   - *五行映射：* 水(6x 最高) ➡️ 金 ➡️ 木 ➡️ 气 ➡️ 火 ➡️ 土(1x 最低)
   - *专属特质【防重入攻击】：* 拥有护盾时，单次巨额攻击最多只能扣除 1 层护盾；每回合首选水/土元素锁牌免算重掷次数。
3. **⚡ 闪电喵 (Volt Kitten) - 敏捷/操控流**
   - *五行映射：* 雷/气(6x 最高) ➡️ 火 ➡️ 金 ➡️ 水 ➡️ 木 ➡️ 土(1x 最低)
   - *专属特质【夹子诅咒】：* 每场战斗限一次，强行“抢跑”窃取 Boss 随机数，使其攻击必定失误，但自身释放的技能属性将陷入不可控的混乱。
